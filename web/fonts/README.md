# Studio typography

Instrument Sans (variable, normal 400–700) is the studio's interface and editorial typeface. IBM Plex Mono Regular is used for timestamps and compact technical values. Both are self-hosted so the studio does not depend on a Google Fonts request during recording.

Sources: [Instrument Sans](https://github.com/google/fonts/tree/main/ofl/instrumentsans), [IBM Plex Mono](https://github.com/google/fonts/tree/main/ofl/ibmplexmono). Their unmodified font files and SIL Open Font License texts are included here.

[Dinamo](https://abcdinamo.com/) informed the hierarchy, scale contrast, restrained spacing and grotesque direction. No Dinamo commercial font files or brand assets are included; these fonts are not presented as Dinamo designs.
