# 제출용 최종 촬영 가이드 — 영어 3분

2026-11-02 / 앱 기준 8688280. 이 문서는 촬영 지시문이며 촬영 완료 증거가 아니다. 이전 DEMO_SCRIPT.md의 확장 시나리오와 평가 선행조건보다 이 문서의 좁힌 범위를 우선한다.

## 확정 범위

**본인 한 명 + 실제 Meta AI, 검색 한 번 + 수동 HOLD 한 번.** 카메라·외부 게스트·추가 기능·대규모 평가 없이 현재 앱의 핵심을 보여준다. 이 영상을 2인 대화 검증이라고 소개하지 않는다. 사람 멘트만 대본이고, AI 답변은 실제 호출 결과 그대로다. SPNS TV의 '대화 중 PD에게 짧게 확인 요청'하는 진행 방식만 참고하며 브랜드·성대모사는 사용하지 않는다.

성공 기준: 실제 질문 → 실제 검색 → 관련 출처가 있는 실제 음성 답변 → 사람의 제어가 보이는 영어 3분 영상. 촬영을 막는 오류만 수정한다.

## A. 촬영 전 준비

1. 헤드폰을 착용하고 Chrome/Edge에서 http://localhost:4400 을 연다. 열리지 않을 때만 프로젝트 폴더 터미널에서 `npm run dev`를 실행한다. 대본은 종이나 별도 기기에 띄운다.
2. Studio controls에서 Meta를 선택한다. **Enable research PD** 체크 → **Save**. 상단 **Research PD: ON**을 확인한다.
3. 녹음·공급자 전송 안내를 확인하고 본인의 동의 체크 → **Connect mic** → **Start session · Meta co-host**.
4. 연습으로 “AI, who wrote the 1993 essay The Coming Technological Singularity? Please look it up and check a source.”라고 말한다. 실제 AI 소리가 들리는지 확인한다.
5. **Film your 3-minute demo · local recording**을 펼친다. **Record this tab + mic** → 현재 스튜디오 탭 선택 → **Share tab audio** 체크. 본인과 AI 음성이 들어가는 짧은 샘플을 녹화한다. AI가 아직 말하지 않았다면 실제 응답이 들어올 때까지 기다린다. 필요하면 일반 후속 질문 후 **Handoff · Ask the co-host**로 다음 응답을 요청한다.
6. **Stop capture** → 미리보기 재생. 내 목소리와 AI가 모두 들리면 준비 완료. **Save local WebM**으로 샘플 저장 → **End session**.
7. 종료를 확인하고 새 세션 시작 → **HOLD · Stop AI**. 도입 설명 중 AI는 멈춰 두되 마이크는 음소거하지 않는다.

## B. 본촬영 시작

**Record this tab + mic** → 스튜디오 탭 + **Share tab audio** → 녹화 시작 후 **Judge view**.

- 마이크를 음소거하거나 연결 해제하면 녹화가 중단될 수 있으므로 계속 켜 둔다.
- 시간은 **영상 녹화 시작** 기준이다. 상단 REC는 세션 시간이라 다르다. Judge view에서는 녹화 타이머가 숨겨지므로 별도 초시계를 사용한다.
- 아래 시간은 진행 기준이며 AI 응답 시각을 보장하지 않는다. 2:55까지 말하고 마지막 5초는 화면을 유지한다. 내장 녹화는 180초에 자동 종료된다.

## C. 영어 대본과 조작 — 위에서부터 읽기

### 0:00–0:20 / 도입 / AI는 HOLD

> When a podcast conversation stalls on a forgotten fact, someone usually asks the producer. This is Meta Conversation Co-host: an AI that listens, checks a requested fact, and returns the floor. I’ll show it with one live microphone.

**조작:** **Resume listening** 클릭. held 상태가 해제되면 다음으로 간다.

### 0:20–0:48 / 맥락을 먼저 말하고 검색 요청

> We’re talking about the technological singularity: machines becoming smarter than people, and why predictions might break down after that point.

잠깐 쉬고:

> I remember an essay from around nineteen ninety-three, but I’ve forgotten the author.

잠깐 쉬고:

> AI, who wrote that essay? Please look it up and check a source for us.

**조작:** 검색 요청에는 Handoff를 누르지 않는다.

### 0:48–1:05 / 검색 중 대화를 이어감

> While you look, I think the interesting question is whether faster thinking also means faster real-world progress. Better ideas still need experiments. I still want the author when you’re ready.

**이후 말을 멈춘다.** 계속 공백을 채우면 AI가 발언할 틈이 없다.

### 1:05–1:35 / 실제 AI 답변을 듣고 출처 표시

**AI 대사는 없다. 실제 생성된 답변을 끝까지 듣는다.** 의도한 참고 대상은 Vinge의 1993년 글이지만 정답을 입력하거나 대신 읽지 않는다. 실제 답변과 출처를 확인한 뒤 테이크를 사용한다.

답변과 관련 출처가 나오면:

> Thanks. That gives us a reference to inspect. The point is to help the conversation move on, not to replace it.

**조작:** 출처 카드가 보이도록 로그를 조금 스크롤한다. 링크를 눌러 다른 탭으로 이동하지 않는다. 일찍 끝났으면 화면을 잠깐 유지하고 새 질문을 추가하지 않는다.

### 1:35–2:10 / 사람이 발언권과 정지를 제어

> For ordinary follow-up questions, I choose when to invite the co-host. What uncertainty should we discuss next?

**조작:** 말을 멈추고 질문 전사가 완료되면 **Handoff · Ask the co-host** 클릭. AI 소리가 실제로 나오면 **본인은 말하지 않은 채 HOLD · Stop AI** 클릭. 2초 정도 기다려 소리가 멈춘 것을 확인한다.

실제로 음성을 멈췄을 때만:

> That was the manual stop button. The people keep control.

이후 HOLD를 유지한다. 이것은 **수동 정지** 시연이다. 자동 끼어들기 중단이라고 설명하지 않는다.

### 2:10–2:40 / Meta 역할과 새 기여

> Meta handles speech recognition, conversation decisions, web research, and whether an answer is still relevant. OpenAI supplies speech synthesis. The app saves the transcript, source evidence, and separate audio locally.

> I reused my React and LiveKit studio. The new work is the Meta co-host pipeline, research controls, and cancellation logic.

**조작:** 앱 안의 출처·전사·공급자 표시를 보여준다. 파일 탐색기로 이동하지 않는다. 산출물은 촬영 뒤 확인한다.

### 2:40–2:55 / 마무리

> This is a working MVP. Responses take time, and sources still need review. The goal is simple: help people keep talking, with an AI producer that knows when to step back.

### 2:55–3:00 / 화면 유지

말을 멈추고 180초 자동 종료를 기다린다. **Studio controls**로 돌아와 **Save local WebM**. 저장 전에 페이지를 닫거나 새로고침하지 않는다. 그 다음 **End session**으로 음원과 전사를 마무리한다.

## E. 여기까지면 촬영 종료

- [ ] 내려받은 영상 전체를 한 번 재생했고 내 목소리와 실제 AI가 알아들을 수 있게 들린다.
- [ ] 답변과 관련 있는 출처가 보인다. 검색 완료 표시는 실제 음성 재생을 대신하지 않는다.
- [ ] 수동 정지 또는 HOLD 상태를 실제 동작에 맞게 설명했다.
- [ ] 영어 설명에 Meta/OpenAI 역할과 기존 스튜디오 재사용이 들어 있다.
- [ ] 실제 파일 길이를 확인했고 키·초대 링크·불필요한 개인정보가 보이지 않는다.

내장 녹화 파일은 WebM이다. 필요한 편집은 앞뒤 정리와 영어 자막 정도로 제한한다. 대기를 줄여 편집하면 **Waiting time shortened**를 표시하고 원본을 보관한다. 편집된 속도를 실제 응답 속도로 주장하지 않는다. 업로드 서비스에서의 영상 처리·재생 확인은 공개 승인 후 단계다.

촬영 후에는 **선택한 WebM 파일 경로와 세션 ID**만 전달하면 된다. 이후는 최종 영상·문구 검수, 저장소/영상 공개 승인, 양식·약관 확인과 제출이다. 추가 기능·외부 게스트·광범위한 평가를 이 영상의 선행조건으로 다시 늘리지 않는다. 이 문서는 공개나 최종 제출에 대한 승인을 대신하지 않는다.
