# 현재 구현과 검증 상태

확인 기준: **2026-10-28**. 대상은 전용 웹 + LiveKit 기반의 음성 우선 v2다. 이전 Discord·영상 데모의 결과를 이 버전의 검증 결과에 합산하지 않는다.

**현재 위치는 짧은 실제 음성 대화가 가능한 시제품 단계다.** 두 엔진·MC 설정·진행 제어·서버 분리 녹음이 구현되어 있고, Gemini Live에서 진행자와 AI의 43초 대화를 확인했다. 방송 회차에 필요한 장시간 안정성·3인 대화·외부 게스트 접속은 남아 있다.

## 확인한 기능

| 영역 | 구현 및 확인 범위 | 남은 확인 |
|---|---|---|
| 음성 연결 | LiveKit 방 참가, GPT-Live/Gemini Live 어댑터, 두 엔진의 짧은 MC 출력 기록 | 동일 조건의 엔진별 10분 사람 대화 |
| MC 설정 | 페르소나 트랙·직접 작성 프롬프트, 스몰토크/첫마디 대기, 엔진별 설정 | 한국어 자연스러움과 진행 품질 평가 |
| 방송 중 제어 | MC에게 넘기기, AI 정지/재개, 귓속말, 사람별 발화 감지 | 실제 정지 지연, 겹말, 잘못된 끼어들기 빈도 |
| 녹음 | 서버 수신 사람 PCM·실제 송출 MC PCM의 분리 WAV, 믹스, 대화록·리포트 | 3인 트랙 정렬·누락·중단 복구, 브라우저 원음 업로드 |
| 관측 | 세션별 지연 표본·추정 비용·이벤트와 엔진 비교 화면 | 충분한 표본의 지연 분포, 실제 청구와의 비교 |
| 게스트 | 초대 토큰·링크와 입장 페이지 코드 | 공개 페이지 배포와 외부 게스트 실접속 |

## 검증 근거

### 코드 검사

2026-10-28에 다음 명령을 확인했다.

| 검사 | 결과 | 범위 |
|---|---|---|
| `npm test` | **29/29 통과** | 오디오 믹서·VAD·화자/전사 처리, 엔진 모의 프로토콜, 설정·초대 링크, 페르소나, WAV·리포트 |
| `npm run typecheck` | **통과** | 서버·공유 코드·테스트와 웹 TypeScript 검사 |
| `npm run build:web` | **통과** | 웹 프로덕션 번들 생성. 500kB 초과 청크 경고는 남아 있으며 실행 실패는 아님 |

모의 프로토콜 검사는 실제 공급자·네트워크·마이크·청취 환경을 검증하지 않는다. 이 결과를 장시간 실제 통화 통과로 해석하지 않는다.

### 실제 세션 기록

가장 최근에 사람 대화와 AI 응답을 함께 확인한 기록은 **2026-10-26 21:41의 Gemini Live 세션**이다.

| 항목 | 기록 |
|---|---|
| 길이 | 리포트 43초, WAV 43.4초 |
| 발화 | 사람 3회, MC 3회 |
| 응답 지연 | **837ms, 579ms** — 두 표본 |
| 끼어들기 이벤트 | 사람이 MC를 끊은 서버 감지 1회 |
| 오류 이벤트 | 기록상 0회 |
| 저장 트랙 | 진행자 WAV, MC WAV, 전체 믹스 WAV |

지연은 에이전트가 음량으로 사람 발화 종료를 판정한 시점부터 MC 첫 음성을 송출한 시점까지다. 청취자가 실제로 듣는 종단 지연과 같지 않다. 리포트의 중앙값·p95 표시를 장시간 성능 판정에 사용하기에는 표본이 부족하므로 원래 두 값을 함께 기록한다. 사람의 끼어들기 이벤트는 "AI가 사람을 잘못 끊은 횟수"와 다른 지표다.

로컬 근거: `output/2026-10-26_2141_gemini-live_f27a/summary.json`, `report.md`와 같은 폴더의 WAV. 이 문서는 집계만 담으며 원본 음성·대화록·개인 설정은 저장소에 포함하지 않는다.

확인 시 `output/`에는 세션 폴더 19개, 종료 요약 18개가 있었다. 종료 요약이 있는 세션은 **4~44초**, 전체 지연 표본은 **3건**, 저장된 게스트 트랙은 **0개**였다. 한 세션은 이벤트와 사람 WAV만 남고 종료 리포트·요약이 없었다. 비정상 종료·복구 검증에 포함할 사례이며, 원인은 이 점검만으로 확정하지 않는다.

## 완료로 표시하지 않는 항목

- **10분 진행자 + AI 대화:** 지연 중앙값 ≤ 1.2초·p95 ≤ 2.0초, 정지 ≤ 300ms, 자연스러움 4/5의 수락 근거가 아직 없다.
- **15분 3인 대화:** 실제 게스트, 겹말, 화자 구분, AI의 불필요한 끼어들기를 확인하지 않았다.
- **장시간 연결·복구:** 재연결·세션 이어받기 코드가 있어도 실제 장시간 시험은 별도다.
- **브라우저 원음 녹음·업로드:** 현재 WAV는 서버가 LiveKit에서 수신한 PCM이다. 네트워크 전송 전 원음을 따로 확보하는 기능은 미구현이다.
- **외부 게스트 페이지·30분 모의 회차:** 공개 배포·외부 접속·전체 회차 흐름의 완료 근거가 없다.
- **영상·캐릭터·장기기억·게스트 자동 조사·편집 UI:** 음성 대화 수락 이후 검토할 후속 범위다.
